# Lab 4

This repository contains C program solutions and detailed algorithm breakdowns for the Lab 4 assignment.

---

## Questions Overview

Each question is housed in its own dedicated folder containing the C source code, the compiled executable, and a specific `README.md` that thoroughly explains the algorithm and its time complexity.

* **Question 1:** Color-Stable Pair Sorter - Grouping pairs by color in $O(n)$ time while preserving numeric order.
* **Question 2:** 2-SUM Problem - Finding if two elements from sets S1 and S2 add up to x in $O(n \log n)$ time.
* **Question 3:** Generalized k-SUM Problem - Finding $k$ elements that sum to a target $T$ in $O(n^{k-1} \log n)$ time.
* **Question 4:** Peak Party Attendance - Using Sweep-Line to find the maximum simultaneous overlapping times in $O(n \log n)$ time.
* **Question 5:** Interval Merging - Merging a list of overlapping intervals in $O(n \log n)$ time.
* **Question 6:** Maximum Interval Coverage - Finding a point on a line covered by the most intervals in $O(n \log n)$ time.
