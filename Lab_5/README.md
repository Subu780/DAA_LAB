# DAA Lab 5

This repository contains the C implementations for Lab 5.

## Lab Overview

This lab consists of the following problems:

*   **Question 1: Find the Median**
    *   **Description:** Finds the median of an array of $N$ elements using a divide-and-conquer approach (similar to Quickselect) to avoid the $\mathcal{O}(N \log N)$ cost of fully sorting the array.
    *   **Directory:** `Question_1/`

*   **Question 2: Find the $K$-th Smallest Element**
    *   **Description:** Locates the $K$-th smallest element in an unsorted array of $N$ elements using a partition-based divide-and-conquer algorithm.
    *   **Directory:** `Question_2/`

*   **Question 3: Quick Sort with File I/O**
    *   **Description:** Generates $N$ elements, writes them to `numbers.txt`, reads them into memory, sorts them strictly using the **Quick Sort** algorithm, and writes the output to `sorted_numbers.txt`.
    *   **Directory:** `Question_3/`

*   **Question 4: Heap Sort with File I/O**
    *   **Description:** Generates $N$ elements (or takes manual input), writes them to `numbers.txt`, reads them back into memory, sorts them strictly using the **Heap Sort** algorithm, and writes the final output to `sorted_numbers.txt`.
    *   **Directory:** `Question_4/`
