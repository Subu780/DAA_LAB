# DAA LAB 8

Dynamic Programming problems, solved in C. Each folder `question_N` has `question_N.c`, `a.out` and its own `README.md`. Every program has a menu: enter 1 to give input manually, or 2 to generate random input.

**1. Minimum Coin Change:** Find the fewest coins (infinite supply of each) that add up to a target amount V. Print -1 if it cannot be made.

**2. Coin Change, Total Number of Ways:** Count the distinct combinations of coins that sum to V, where order does not matter (1+2 and 2+1 are the same).

**3. Longest Common Subsequence (LCS):** Find the length of the longest common subsequence of two sequences and print the subsequence itself.

**4. Longest Increasing Subsequence:** Find the length of the longest strictly increasing subsequence of an array. Solved with both the O(n²) DP and the O(n log n) method.

**5. Maximum Sum Increasing Subsequence:** Find the largest possible sum of a strictly increasing subsequence of positive integers.

**6. Edit Distance with Traceback:** Find the minimum insertions, deletions and substitutions needed to turn string A into string B, and print the sequence of operations.

**7. Rod Cutting with Reconstruction:** Find the maximum revenue from cutting a rod of length n into pieces, and print the lengths of the pieces used.

**8. Optimal Binary Search Tree (OBST):** Given keys with search probabilities and dummy keys for failed searches, find the binary search tree with the minimum expected search cost and print its structure.

**9. Collatz Conjecture:** Simulate the 3n+1 sequence (an open problem) for a single starting value and for every value in an interval [a, b], reporting steps, peak value and overflow handling.
